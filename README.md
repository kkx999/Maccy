## 下载与安装

**当前版本：** `v0.30.0-firefox.1`  
**架构：** Apple Silicon（`arm64`，适用于 M 系列芯片）  
**安装包：** [Maccy-0.30.0-Firefox-arm64.zip](https://github.com/kkx999/Maccy/releases/download/v0.30.0-firefox.1/Maccy-0.30.0-Firefox-arm64.zip)

1. 下载 ZIP，解压得到 `Maccy.app`。
2. 如果之前安装过 Maccy，**先备份需要保留的剪贴板历史和设置**，然后完全退出原版。
3. 将 `Maccy.app` 拖入 macOS「应用程序」文件夹，按需要替换旧版。
4. 第一次打开如果被 macOS 拦截，可在「系统设置 → 隐私与安全性」中选择 **仍要打开**；自动粘贴功能可能需要重新授予「辅助功能」权限。

> 当前发布的安装包仅构建了 `arm64` 版本，不提供 Intel Mac 安装包。使用 Ad-hoc 签名，**未经 Apple Developer ID 签名或 Apple 公证**。

## 为什么制作这个版本？

Firefox 无痕窗口复制网页正文时，可能向 macOS 系统剪贴板写入 `org.nspasteboard.ConcealedType` 保密标记。官方 Maccy 0.30.0 会跳过带此标记的内容：普通粘贴正常，但历史记录里没有。

此修改版在 **Firefox 为前台应用** 时，允许处理上述保密标记，同时保留其他应用原有的过滤行为。修改范围集中在 `Maccy/Clipboard.swift`，不改变原版的界面和主要操作逻辑。

| 使用场景 | 行为 |
| --- | --- |
| Firefox 普通模式 | 正常记录 |
| Firefox 无痕模式复制网页正文 | **可以记录（修复项）** |
| Firefox 无痕模式复制地址栏 | 正常记录 |
| Chrome 普通及无痕模式 | 保持原有行为 |
| 其他应用和密码管理器 | 保留原版过滤规则 |

**修改细节：** 仅针对 Firefox 放宽 `ConcealedType`；`TransientType` 和 `AutoGeneratedType` 继续被忽略。此版本不能保证所有浏览器版本或所有复制场景均能记录。

## 基本使用

- **⇧ Shift + ⌘ Command + C**：打开剪贴板历史。
- **Enter**：将选中记录复制到剪贴板。
- **⌥ Option + Enter**：选择记录并自动粘贴（需开启相关设置及权限）。
- **⌥ Option + P**：固定或取消固定记录。
- **⌘ Command + ,**：打开 Maccy 设置。

其他快捷键、历史搜索、固定记录、忽略应用等功能沿用官方 Maccy 0.30.0。

## 从源码构建

本仓库只维护一个默认分支：`main`。

- 推送到 `main` 会触发 [GitHub Actions](https://github.com/kkx999/Maccy/actions) 编译，并在成功后提供可下载的构建产物（Artifacts）。
- **普通提交不会覆盖现有 Releases。**
- 需要发布新版本时，使用新的 `v0.30.0-firefox.*` 标签（例如 `v0.30.0-firefox.2`）触发正式发布；已有同名 Release 不会被覆盖。
- 构建环境是 GitHub Actions 的 macOS 运行器及 Xcode，产出 Apple Silicon `arm64` 的 `Maccy.app`。

完整步骤见 [CUSTOM-BUILD.md](./CUSTOM-BUILD.md)。

## 注意事项

**隐私提醒：** 此修改会使 Firefox 无痕窗口复制的文字也可能留在 Maccy 历史中，包括密码、验证码或其他敏感信息。无痕窗口关闭并不会自动清理这些记录，请自行定期清理。

**更新提醒：** 不建议让这个修改版自动升级到上游官方 Maccy，因为上游更新可能覆盖本仓库的修复。新版本请从本仓库 [Releases](https://github.com/kkx999/Maccy/releases) 获取。
